# Language and artifact names

This release supports English and Russian. Choose one project language from the user's request and keep it unchanged unless the user explicitly switches it.

Prompts may use an English canonical label in quotation marks. Resolve that label to the actual project filename below. Never create both language variants in one project.

| Canonical artifact | English filename | Russian filename |
|---|---|---|
| Project passport | `Project passport.docx` | `Паспорт проекта.docx` |
| Parameters | `Parameters.xlsx` | `Параметры.xlsx` |
| Client questions | `Client questions.html` | `Вопросы клиенту.html` |
| Quote | `Quote.docx` | `Коммерческое предложение.docx` |
| Market research | `Market research.docx` | `Исследование рынка.docx` |
| Unit cost | `Unit cost.xlsx` | `Себестоимость.xlsx` |
| Client values letter | `Client values letter.docx` | `Письмо клиенту, значения.docx` |
| Financial model | `Financial model.xlsx` | `Финмодель.xlsx` |
| Interactive model | `Interactive model.html` | `Интерактивная модель.html` |
| Reconciliation | `Reconciliation.xlsx` | `Сверка интерактивной модели.xlsx` |
| Meeting script | `Meeting script.docx` | `Сценарий встречи.docx` |

Use these sheet names:

| Canonical sheet | English | Russian |
|---|---|---|
| Parameters | `Parameters` | `Параметры` |
| Model | `Model` | `Финмодель` |
| Scenarios | `Scenarios` | `Сценарии` |

For a backup made before editing, append ` before edits` in English or `. До правок` in Russian before the extension.

If an existing project already uses another clear naming convention, preserve it and record the mapping in the project passport instead of renaming files without permission.
