# Step 7. Handover

Write the output in the language of the user's request.

## Prompt 7.1. Meeting script and client questions

```
Prepare a client meeting script for 60 to 90 minutes around the presentation mode of «Interactive model»: the order of the screens, the minutes for each, the screen at which to step out to the sliders and which parameters to move in front of the client, and when to hand the sliders over to them.

Then write 10 to 12 questions the client is likely to ask about this model, starting with the most uncomfortable: the funding gap, whether the main revenue driver is realistic, what happens if fixed costs rise, the borrowing, and why the figures come from the market rather than from them. Answer each in two or three sentences with figures from the model and, where it fits, name the slider that demonstrates it.

Save it to the project folder as «Meeting script».
```

Get the figures for the answers by running the model for each variant, not by estimating. «What if rent rises 20 per cent» is a separate calculation, not a guess.

**STOP 8.** Before anything goes to the client, show the list of files.

## What goes to the client

| File | Why |
|---|---|
| Interactive model | The main deliverable, the client works with it themselves |
| Analytical note | Downloaded from the page, the finance professional types the client's name by hand |
| Financial model spreadsheet | On request, if the client wants to see the calculation |

The research, the unit cost calculation, the reconciliation and the meeting script stay with the finance professional.
