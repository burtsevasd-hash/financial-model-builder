# Структура файла «Финмодель.xlsx». Шаблон

Три листа. Расчётных чисел руками нет нигде: только формулы со ссылками.

## Лист «Параметры»

Единственный лист ввода. Столбцы: Блок | Параметр или константа | Единица | Значение | Источник или комментарий | Как используется.

Блоки по порядку: управление моделью; выручка; переменные расходы; персонал; постоянные расходы; стартовые вложения; оборотный капитал; налоги; финансирование и оценка; технические константы; проверка штата.

Ячейки ввода светло-голубые. Технические константы (ноль, единица, месяцев в году, допуск проверки) выносятся отдельным блоком, чтобы в формулах не было чисел.

## Лист «Финмодель»

Столбцы: Строка | Единица | Как считается | Итого | М1 … М36.

Блоки строк по порядку:

1. **Вводные и драйверы.** Номер месяца, календарный месяц и год, месяц после открытия, признак «точка работает», выбранный сценарий, сценарные величины, коэффициенты индексации по группам расходов, рабочие дни, выход на план, сезонность, доли каналов.
2. **ОПиУ.** Продажи, налог с продаж, если он есть, выручка без налога, прямые затраты, валовая прибыль и рентабельность, переменные расходы по статьям, персонал по должностям, взносы, постоянные расходы по статьям, амортизация, операционная прибыль и рентабельность, проценты по займам, налоговые расходы, налоговая база, налог, чистая прибыль.
3. **Оборотный капитал.** Запасы, дебиторская и кредиторская задолженность на начало и конец, изменения, чистый оборотный капитал.
4. **ОДДС, операционная деятельность.** Поступления, оплата сырья, комиссии, выплаты персоналу, аренда, коммунальные, маркетинг, прочие, уплата налогов и взносов, итог.
5. **ОДДС, инвестиционная деятельность.** Каждая строка сметы в свой месяц оплаты, резерв, итог.
6. **ОДДС, финансовая деятельность.** Взнос собственника, получение займа, остаток долга, аннуитет, проценты, погашение, комиссии, выплаты собственнику, итог.
7. **Деньги.** Чистый поток, остаток на начало и конец, дефицит до минимального остатка.
8. **Показатели проекта.** Поток проекта до финансирования, накопленный поток, терминальные возвраты, поток для NPV и IRR, потребность в инвестициях, месяц окупаемости.
9. **Контрольные проверки.** Доли каналов, баланс денег, покрытие смен персоналом, статус по каждой.

## Лист «Сценарии»

1. Переключатель сценария одной ячейкой со списком.
2. Таблица три на три: ключевые параметры по строкам, сценарии по столбцам.
3. Основные показатели выбранного сценария по годам, ссылками на модель.
4. Показатели проекта: потребность, месяц окупаемости, NPV, IRR, максимальный дефицит, остаток долга.
5. Контроль модели: статусы проверок с листа «Финмодель».
6. Сравнение сценариев через таблицу данных.
7. Анализ чувствительности, ранг параметров, граница.
8. Выводы: 5–7 фраз, каждая с числом.
