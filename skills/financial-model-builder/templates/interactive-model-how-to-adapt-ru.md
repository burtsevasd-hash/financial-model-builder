# Как переделать образец под новый проект

Файл `Интерактивная модель, образец.html` это рабочая страница по пекарне в Казани. Он собран из четырёх частей, менять нужно три из них.

## 1. Данные проекта, блок `const BASE` и `const SCEN`

В начале скрипта. `BASE` это все параметры и константы с листа «Параметры» в виде одного объекта: горизонт, первый месяц, доли, ставки, оклады, смета, налоги, финансирование. `SCEN` это таблица сценариев три на три.

Берётся выгрузкой из «Финмодель.xlsx»: прочитать лист «Параметры», собрать объект, подставить. Названия ключей оставить как в образце там, где смысл совпадает, добавить свои там, где у нового бизнеса другие статьи.

## 2. Расчётный движок, функция `runModel`

Это построчный перенос листа «Финмодель». Номера строк в коде совпадают с номерами строк Excel: `r[39]` это выручка без налога, `r[69]` чистая прибыль, `r[117]` остаток денег и так далее.

Порядок работы:

1. Выгрузить из Excel формулы листа «Финмодель» по одной колонке месяца.
2. Перенести каждую строку в движок в том же порядке. Два прохода: сначала календарь, индексы и продажи, потом всё остальное, потому что признак налога на продажи смотрит на весь год.
3. Сверить движок с кэшированными значениями Excel по всем месяцам и всем строкам. Расхождение больше рубля это ошибка переноса, а не округление.
4. Только после сверки собирать интерфейс.

Если у нового бизнеса нет какой-то строки, удалить её и все ссылки на неё, а не оставлять нулём.

## 3. Движки, массив `SLIDERS` и `STAFF`

`SLIDERS` это список параметров из ранга чувствительности шага 5: ключ, ранг, название, единица, границы в долях от базового значения, шаг, подпись, формат вывода. Флаг `bad: 1` означает, что рост величины ухудшает результат, флаг `abs: 1` что движок задаёт абсолютный сдвиг, а не множитель.

`STAFF` это счётчики численности. Нужны, если в модели есть проверка покрытия смен.

## 4. Тексты, что меняется всегда

- Шапка: ниша, город, горизонт, дата модели.
- Блок «Источники и допущения» внизу вкладки «Модель»: четыре карточки по вашим источникам.
- Записка: все абзацы под новый бизнес, числа подставляются автоматически через `data-k`.
- Слайды презентации: функция `buildDeck`, десять экранов, цена решений считается через `altMetrics`.

## Что проверить перед сдачей

- Три сценария на странице совпадают с листом «Сценарии» в Excel до рубля.
- Кнопка сброса возвращает базовые значения.
- Печать записки тёмная по белому.
- Нет длинных тире, нет внешних ссылок на библиотеки, страница работает без интернета.
- Нет названия компании и имён.
