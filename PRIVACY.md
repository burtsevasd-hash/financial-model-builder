# Privacy Policy

Effective date: 19 November 2026.

Financial Model Builder is a skills-only plugin. It contains instructions and templates, has no developer-operated server, creates no separate user account, and does not independently transmit data to the developer.

## Data used

The plugin may work with business descriptions, assumptions, planned financial figures, and model files that the user voluntarily provides in ChatGPT or Codex. It does not require personal names, phone numbers, email addresses, physical addresses, government identifiers, payment-card data, passwords, or access keys.

## Purpose

Provided data is used only to perform the user's request: building, reviewing, or updating a financial model and related materials.

## Sharing and processing

The plugin has no separate network service and does not send user data to the developer. Processing by ChatGPT or Codex is governed by the user's OpenAI account, product settings, and applicable OpenAI terms. When external research is requested, the skill instructs the agent to use an anonymized description and not to include client identifiers in search queries.

## Retention

The developer does not receive or retain user data. Conversation history and workspace files may be retained by the service and environment selected by the user according to that service's settings.

## User controls

Users can withhold personal data, remove files from their workspace, and manage conversation history using the controls of the service they use. Users should review all deliverables for identifiers before sharing them externally.

## Contact

For privacy or support questions, open an issue at https://github.com/burtsevasd-hash/financial-model-builder/issues.
